# 🌤️ Airflow Weather Tracker Pipeline

Локальный пет-проект дата-инженера. Развернут внутри **Docker** на macOS для автоматизации сценариев обработки данных.

## 🚀 Что делает проект:
1. **Extract**: Имитирует или собирает метрики погоды (температуру и скорость ветра).
2. **Transform**: Анализирует критические погодные условия с помощью `BranchPythonOperator`.
3. **Load**: Разветвляет логику пайплайна и выводит персонализированные рекомендации в логи Airflow.

## 🛠️ Стек технологий:
* **Apache Airflow 2.10.2** (LocalExecutor)
* **Docker / Docker Compose**
* **Python 3**
* **VS Code**

## 💻 Как запустить локально:
1. Запустите Docker Desktop.
2. Поднимите контейнеры: `docker compose up -d`
3. Откройте интерфейс в браузере: `http://localhost:8080` (логин/пароль: `airflow`).
